# Most Wanted MOD | Junkman, Markers & Garage 25 | v1.4.0 — modded by YBPUT (tidak resmi)

Modifikasi dari [RanggaCasper/MostWanted-Android](https://github.com/RanggaCasper/MostWanted-Android) v1.4.0. Proyek asli GPL-3.0; modifikasi ini juga GPL-3.0.
Source ada di repo ini, folder `junkman-mod/`.

## Baru di rilis ini
- Garasi Safe House: batas mobil **15 -> 25** (batas nyata save).
- **Perbaikan crash** saat memilih marker pink slip ketika garasi penuh (freeze lalu force close).
- Pembelian mobil saat garasi penuh diblokir dengan pesan "no more room".

## Tetap ada
- Marker setelah mengalahkan Blacklist: 2 -> 6
- Junkman tidak habis; semua kategori Backroom tampil

## Pasang
1. Hapus instalasi resmi dulu (tanda tangan berbeda). Backup `MostWanted/hdd`.
2. Pasang APK ini.
3. Taruh game milik sendiri di `/storage/emulated/0/MostWanted`.

APK tidak berisi aset game. Varian patch: F.
File: `NAMA_APK_BARU.apk`
SHA-256 APK: `ISI_SETELAH_APK_JADI`

Diketahui: garasi maksimal 25. Jika garasi penuh, mobil pink slip tidak masuk (tanpa crash); jual satu mobil dulu.
